# 生成時のピッチ補正

F0 モデルの出力を、狙った音高へ寄せる 2 段の処理です。どちらも学習を含まない決まった計算で、実装は `prettypitch/correction.py`、呼び出しは `infer.synthesize_f0()` です。

![ピッチ補正](fig/pitch_correction.png)

## 何を狙うか

狙う値（target）は楽譜のノート音高です。生成された F0 がいまどの高さに聞こえているか（perceived）を推定し、その差を埋めます。

perceived の推定は、学習時に使う F0 の代表値の推定に似た計算方法を使います（[representative_pitch.md](representative_pitch.md)）。**しかし目的が異なるため、いくつかの違いがあります。**

学習ラベルは「実際に歌われた音高を忠実に写す」ためのもので、正確に推定できる部分は精度を求める一方、ある程度のエラーを許容しています。補正の perceived は意図していないF0に補正されないことを重視しており、より安全な値の取り方をしています。

| | 学習ラベル | 補正の perceived |
|---|---|---|
| w_e | 非対称 0.8 / 0.3 | 対称 Tukey α = 0.5 |
| w_d | SG の 1 階微分（傾き） | SG からの残差 |
| w_t の σ | 1.0 半音 | 0.5 半音 |
| 短いノートの山検出 | あり | なし |

## ノート境界の決め方

第 1 段はノートごとに 1 つの補正量を決めます。そのために、フレーム列のどこからが次のノートかを知る必要があります。

音高の数値の変化では決めません。同じ高さのノートが続いた場合も、ノートごとに補正を入れるためです。代わりに音素の並びから決めます。次のいずれかが始まるフレームが境界です。

- 音高の値を持つ音素、つまり核音素
- 休符
- フレーズの先頭

## 第 1 段 — ノートごとの定数オフセット

ノート区間ごとに、知覚代表値と目標値の差 `c = target − perceived` を 1 つ求め、区間全体に同じ値を足します。休符は `c = 0` です。

区間内で定数なので、ビブラートもしゃくりも形がそのまま残ります。ノートが丸ごと平行移動するだけです。

つないだ `c` のベクトルを σ = 30 ms のガウシアンで平滑して、ノート境界をなめらかに繋ぎます。

## 第 2 段 — 窓で形を整える

核音素のフレーム列に対して、フレームごとの実際のずれに比例した補正を当てます。

```
correction = 窓 × α × (target − F0)
```

α は既定 0.8 です。窓は非対称 Tukey で、先頭 0.6・末尾 0.1 の長さでコサインテーパーします。

- **先頭を長くテーパー**すると、入口のしゃくりが残ります。歌い出しの表情なので消したくありません。
- **末尾を短くテーパー**すると、平坦部が終わり近くまで伸びます。後半のオーバーシュートを最後まで補正できます。

`window='hann'` にすると中央がピークの窓になり、中央だけ引き寄せて両端を残します。

## 掛ける順番

どちらも **plain にだけ** 当てます。ビブラートを足す前です。振動が混ざった信号で代表値を推定すると、推定が狂います。

## 切り方

```python
out = infer.synthesize_f0(model, cfg, score, correction=False, hann_alpha=0.0)
```

`correction=False` で第 1 段、`hann_alpha=0.0` で第 2 段が止まります。A/B を取るときに使います。

## 主な既定値

`synthesize_f0()` から渡せるもの。

| 引数 | 既定 | 意味 |
|---|---|---|
| `hann_alpha` | 0.8 | 第 2 段の強さ（0 で無効） |
| `hann_window` | `tukey` | 第 2 段の窓（`hann` も選べる） |
| `hann_lead_taper` | 0.6 | 第 2 段の窓の先頭テーパー（母音長比） |
| `hann_trail_taper` | 0.1 | 第 2 段の窓の末尾テーパー |

第 1 段のハイパーパラメータは `synthesize_f0()` に口が無く、固定です。変えるなら `apply_pitch_correction()` を直接呼びます。

| 引数 | 既定 | 意味 |
|---|---|---|
| `sigma_st` | 0.5 | 第 1 段 w_t の σ [半音] |
| `smooth_sigma_ms` | 30.0 | 第 1 段の補正量の平滑 σ |
