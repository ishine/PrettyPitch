# F0 代表値の推定

楽譜を使わずに学習するために、歌声の F0 そのものから「このノートの音高はいくつか」を決めます。これが代表値で、核音素 1 つにつき 1 個の連続 MIDI 値です。メリスマの「あ あ あ」なら 3 個です。

実装は `prettypitch/pitch.py` の `nucleus_values()` です。

![代表値推定](fig/representative_pitch.png)

## 何のために要るか

楽譜ありの歌声合成なら、ノートの音高は入力に書いてあります。楽譜フリーではそれが無いので、モデルに与える条件（どの高さを歌うか）を音声側から作らなければなりません。

この資料が説明するのは**学習側**の代表値です。baseline（音高の段々）を組み立てる土台になり、モデルはこの baseline からのずれを学びます。

同じ重みの族は生成時のピッチ補正でも使いますが、**設定は別です**。目的が違うためで、対応表は [pitch_correction.md](pitch_correction.md) にあります。

## 推定のしかた

Blaauw & Bonada (2017) の知覚ピッチ推定を土台にしています。核音素の区間について、3 つの重みを掛けた加重平均を取ります。

| 重み | 意味 | 効果 |
|---|---|---|
| w_e | 端のテーパー（非対称 Tukey・前 0.8 / 後ろ 0.3） | 前後の音素へのトランジション部分を軽くする |
| w_d | 安定度 1 / min(1 + k·\|dF0/dt\|, cap) | 動いているところを軽くする |
| w_t | 目標近接 exp(−(F0 − target)² / 2σ²)、σ = 1 半音 | しゃくりやポルタメントを外れ値として捨てる |

w_t には目標値が要りますが、楽譜が無いので区間の中央値から始めて、`target ← 加重平均` を 2 回繰り返します。中央値はしゃくりに強いので、初期値として十分です。

## w_d は傾きで測る

Savitzky-Golay 平滑からの残差、つまりギザギザさで測る手もありますが（`stability='blaauw'`）、まっすぐな傾斜には 3 次多項式が当たってしまうので反応しません。しゃくりの最中がいちばん重くなるという逆転が起きます。

既定では SG の 1 階微分（半音/秒）の大きさで測ります。平らなところほど重くなり、傾いていれば軽くなります。

## 短いノートの山を拾う

子音のあとの短い母音は「深い谷 → 山 → 次の音への下降」という形になります。中央値からブートストラップすると頂点が外れ値として捨てられ、代表値が谷と山の間に落ちます。

次の 3 条件がそろったときだけ、頂点付近の帯（頂点から 0.75 半音以内）の平均に置き換えます。

- 核音素が 300 ms より短い（長い核の山はビブラートや行き過ぎなので触らない）
- 頂点 − 核内の中央値 ≥ 1 半音（ノートの大半が頂点より下＝山形）
- 極大の卓立 ≥ 1 半音

ずれの大きさは 1 ノートあたり数十セントですが、「ノートの上に乗る」か「ノートの下に居る」かの差になります。

## 無声化した母音

日本語の無声母音（A I U E O）は有声フレームがほとんど無いこともあります。既定（`devoiced_fill='interp'`）では、保存してある補間済み F0 の上でそのまま推定します。

こうすると無声母音も楽譜記号として一人前になります。モデルは無声母音を通る補間 F0 を生成するように学び、利用者は楽譜に無声母音を書けます。

## 主な定数

| 定数 | 既定 | 意味 |
|---|---|---|
| `TARGET_SIGMA_ST` | 1.0 | w_t の σ [半音] |
| `SG_WINDOW_MS` | 55.0 | Savitzky-Golay 窓幅 |
| `SLOPE_K` / `SLOPE_CAP` | 0.5 / 15.0 | w_d の傾き係数と下限 |
| `CREST_MAX_MS` | 300.0 | 山検出の対象となる核の長さ上限（0 で無効） |
| `CREST_BAND_ST` | 0.75 | 頂点から何半音以内を平均するか |
| `N_ITER` | 2 | target の固定点反復回数 |
